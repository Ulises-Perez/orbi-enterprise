Cuándo conviene escribirnos y cuándo no

Preferimos decirlo en el primer correo antes que en la tercera reunión.

Encaja

  • La operación funciona y el software quedó corto.
  • Hay un proceso manual que se come horas cada semana.
  • Necesitás cobrar online y hoy se cobra por transferencia.
  • La web actual no se puede editar sin llamar a alguien.

No encaja

  • Campañas de publicidad, redes sociales o posicionamiento pagado.
  • Una web de una página para ayer y sin contenido definido.
  • Soporte de computadores, redes o equipos.
  • Un proyecto sin responsable del lado del negocio.
